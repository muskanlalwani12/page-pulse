# 🚀 Page Pulse - Full Stack SEO Website Auditor

Page Pulse is a full-stack SEO auditing tool that analyzes websites and provides instant SEO health reports.

## 🌐 Live Demo

Frontend:
https://page-pulse-one-alpha.vercel.app

Backend:
https://page-pulse-tn56.onrender.com

---

## Features

✅ SEO Score Analysis  
✅ Website Metadata Analysis  
✅ Performance Metrics  
✅ Missing Image ALT Detection  
✅ SEO Recommendations  
✅ Audit History  
✅ PDF Export  
✅ Dark Mode  
✅ Responsive UI  

---
